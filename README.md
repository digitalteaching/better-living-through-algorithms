## Aufbau jeder Seite

1. **Get the gist:** Überschrift, Zusammenfassung, Schlüsselzitat
2. **Read closely:** drei Analyseschwerpunkte mit Beleg, Technik und Wirkung
3. **See the bigger picture:** Einstellungskurve der Erzählerin, Funktion im Plot, Diskussionsfrage
